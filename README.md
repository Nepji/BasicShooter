<h1 align="center" id="title">Basic Shooter</h1>

<p id="description">Basic Shooter is a third-person shooter game developed using Unreal Engine 5. The project showcases core gameplay mechanics such as shooting healing and ammo pickup. Players can choose from different maps and weapon types allowing for varied combat scenarios. Opponents in the game are AI-controlled bots providing continuous action and challenge. Designed as a foundational shooter experience Basic Shooter demonstrates essential features expected in modern third-person action games.</p>
